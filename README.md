# Sparnatural Query Builder

Visual query builder for domain users, configured automatically from your data and shapes

[![eccenca Corporate Memory][cmem-shield]][cmem-link] [![copier][copier-shield]][copier]

User documentation: [DOCUMENTATION.md](DOCUMENTATION.md). Design and plan: [docs/superpowers](docs/superpowers).

## Layout

| Path | Content |
|---|---|
| `src/sparnatural.html`, `src/sparnatural-app.js` | the page and its DOM glue |
| `src/lib/*.js` | tested logic (browser globals `CmemSparnatural.*` and node modules): parameters, links, SPARQL, statistics, shapes, config generator, cache, theme |
| `src/sparnatural-theme-cmem.css` | Sparnatural colors mapped to CMEM `--eccgui-*` tokens |
| `src/vendor/` | pinned third-party files (`task vendor`, see `src/vendor/NOTICE.md`) |
| `src/test/` | unit tests, fixtures recorded from a CMEM instance with the product data demo |
| `sparnagit-sparnatural-service-project/views/sparnatural.json` | application view (`cmemc admin view export sparnatural`) |
| `sparnagit-sparnatural-service-project/projects/sparnatural-service/` | Build project; `resources/` is generated by `task build-project` |

## Development

- `task test` runs the unit tests (node ≥ 20, no npm dependencies).
- `task build` builds the package (`build-project` copies `src/` into the project resources first).
- `cd src; bash scripts/dev-upload.sh` uploads the page into an installed package for quick browser checks
  (`CHANGED_ONLY=1` skips `vendor/`).
- `cd src; bash scripts/record-fixtures.sh` re-records the test fixtures (needs the product data demo package on the
  current cmemc connection).
- `cd src; task vendor` downloads the pinned third-party files again.
- Run [task](https://taskfile.dev/) to see all major development tasks.
